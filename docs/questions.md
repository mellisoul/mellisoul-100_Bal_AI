## Тема «Функции в Python»

**№3. Уровень 1, тест, стр. 2**
Какое ключевое слово используется для объявления функции в Python?
A) fun B) define C) function D) def
Ответ: def. Объяснение: функция в Python объявляется ключевым словом def.

**№4. Уровень 1, открытый, стр. 2**
Как называется короткая анонимная функция из одного выражения в Python?
Ответ: лямбда-функция. Объяснение: лямбда-функция — это короткая анонимная функция из одного выражения.

**№5. Уровень 2, тест, стр. 2**
Что произойдет, если в функции отсутствует оператор return или он записан без значения?
A) Функция вернет значение None B) Произойдет ошибка выполнения C) Функция вернет пустую строку D) Функция вернет 0
Ответ: функция вернет значение None. Объяснение: если return отсутствует или записан без значения, функция возвращает None.

**№6. Уровень 2, открытый, стр. 2**
В чем разница между параметрами и аргументами функции согласно материалу?
Ответ: параметры — это имена, перечисленные в определении функции (например, width и height в def area(width, height)), а аргументы — это конкретные значения, которые передаются при вызове (например, числа 3 и 4 в area(3, 4)). Объяснение: параметры задаются при описании функции, а аргументы подставляются в момент её вызова.

**№7. Уровень 3, тест, стр. 2**
Какая ошибка возникает, если использовать изменяемый объект (например, список) в качестве значения аргумента по умолчанию в определении функции?
A) Значение списка будет автоматически сбрасываться до пустого при каждом новом вызове функции. B) Python выдаст синтаксическую ошибку (SyntaxError) при попытке запустить код. C) Функция будет выбрасывать исключение TypeError при каждом вызове без этого аргумента. D) Список будет общим для всех вызовов функции, так как значения по умолчанию вычисляются один раз в момент определения функции.
Ответ: D. Объяснение: значения по умолчанию вычисляются один раз при определении функции, поэтому изменяемый объект становится общим для всех последующих вызовов.

**№8. Уровень 3, открытый, стр. 2**
Напишите короткую лямбда-функцию, которая принимает одно число и возвращает его удвоенное значение.
Ответ: `lambda x: x * 2`. Объяснение: лямбда-функция объявляется ключевым словом lambda, за которым следуют параметр, двоеточие и выражение для возвращаемого результата.

**№9. Уровень 4, тест, стр. 2**
Какая частая ошибка связана с использованием оператора print вместо return внутри функции?
A) print превращает функцию в анонимную лямбда-функцию B) print вызывает синтаксическую ошибку в теле функции C) print автоматически завершает выполнение функции без возврата значения D) print только выводит значение на экран, но не передаёт его вызывающему коду
Ответ: D. Объяснение: при использовании print вместо return вызывающий код не получает результат, так как print выводит данные только на экран.

**№10. Уровень 4, открытый, стр. 2**
Объясните, почему использование изменяемого объекта (например, пустого списка) в качестве значения по умолчанию в объявлении функции (например, `def append_to(element, target=[])`) считается опасной практикой, и укажите правильный способ решения этой проблемы.
Ответ: значения по умолчанию вычисляются один раз в момент определения функции, а не при каждом вызове. Из-за этого список становится общим для всех вызовов функции, накапливая элементы. Правильный приём — использовать None в качестве значения по умолчанию, а сам список создавать внутри тела функции при каждом вызове.

**№11. Уровень 5, тест, стр. 2**
Какая особенность поведения Python связана с вычислением значений по умолчанию для параметров функций?
A) Изменяемый объект в качестве значения по умолчанию автоматически копируется для каждого нового вызова функции. B) Значения по умолчанию вычисляются в момент импорта модуля, но не могут быть изменяемыми типами данных. C) Значения по умолчанию вычисляются один раз — в момент определения функции, из-за чего изменяемый объект в качестве значения по умолчанию становится общим для всех вызовов. D) Значения по умолчанию вычисляются при каждом вызове функции заново.
Ответ: C.

**№12. Уровень 5, открытый, стр. 2**
Опишите потенциальную проблему при создании рекурсивной функции в Python согласно материалу, назовите возникающее исключение при её отсутствии и укажите способ оптимизации повторных вычислений в рекурсии.
Ответ: у рекурсии обязательно должен быть базовый случай, иначе возникнет ошибка RecursionError. Повторные вычисления в рекурсии можно ускорить с помощью декоратора functools.lru_cache, который запоминает результаты уже выполненных вызовов.

## Тема «Классы и объекты»

**№13. Уровень 1, тест, стр. 3**
Что представляет собой класс в Python согласно материалу?
A) Шаблон для создания объектов B) Специальный метод для установки атрибутов C) Экземпляр конкретного объекта D) Функция для работы с файлами
Ответ: A. Объяснение: в тексте прямо указано, что класс — это шаблон для создания объектов.

**№14. Уровень 1, открытый, стр. 3**
Какой метод вызывается автоматически при создании объекта и используется для начальной установки атрибутов?
Ответ: `__init__`.

**№15. Уровень 2, тест, стр. 3**
Что представляет собой класс в терминологии объектно-ориентированного подхода?
A) Шаблон для создания объектов B) Экземпляр конкретного объекта C) Встроенный метод для вычисления значений D) Функция для инициализации атрибутов
Ответ: A.

**№16. Уровень 2, открытый, стр. 3**
В чем заключается разница между атрибутом класса и атрибутом экземпляра?
Ответ: атрибут класса является общим для всех экземпляров этого класса, в то время как атрибут экземпляра принадлежит конкретному объекту.

**№17. Уровень 3, тест, стр. 3**
Какой класс является родительским в объявлении `class Student(Person):`?
A) super B) Person C) self D) Student
Ответ: B. Объяснение: в конструкции наследования class Student(Person) имя в скобках указывает на родительский класс.

**№18. Уровень 3, открытый, стр. 3**
Напишите фрагмент кода на Python, демонстрирующий создание класса Cat с методом `__init__`, который принимает имя кота и сохраняет его в атрибут объекта с помощью параметра self.
Ответ:
```python
class Cat:
    def __init__(self, name):
        self.name = name
```
