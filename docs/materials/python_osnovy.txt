Основы программирования на Python
Учебное пособие для студентов первого курса

Глава 1. Переменные и типы данных

Переменная в Python — это имя, которое ссылается на объект в памяти. Переменную не нужно объявлять заранее: она создаётся в момент первого присваивания, например x = 10. Python — язык с динамической типизацией: тип определяется значением, а не переменной, поэтому одной и той же переменной можно сначала присвоить число, а затем строку.

Основные встроенные типы данных: int — целые числа, float — числа с плавающей точкой, str — строки, bool — логические значения True и False, NoneType — специальное значение None, означающее отсутствие значения. Узнать тип объекта можно функцией type(), например type(3.5) вернёт <class 'float'>.

Числа типа int в Python не имеют ограничения по размеру, поэтому выражение 2 ** 100 вычисляется точно. Числа float хранятся приближённо, поэтому 0.1 + 0.2 даёт 0.30000000000000004, а не ровно 0.3. Для сравнения чисел с плавающей точкой используют функцию math.isclose().

Оператор / всегда возвращает float: 7 / 2 равно 3.5. Оператор // выполняет целочисленное деление с округлением вниз: 7 // 2 равно 3, а -7 // 2 равно -4. Оператор % возвращает остаток от деления: 7 % 2 равно 1.

Строки неизменяемы: после создания строку нельзя изменить по месту. Выражение s[0] = 'A' вызовет ошибку TypeError. Чтобы получить изменённую строку, создают новую, например s = 'A' + s[1:]. Срез s[a:b] возвращает символы с индекса a включительно до индекса b не включительно.

Преобразование типов выполняется функциями int(), float(), str(). Вызов int('42') вернёт число 42, а int('4.2') вызовет ошибку ValueError, потому что строка не является записью целого числа. Функция input() всегда возвращает строку, поэтому для работы с числом ввод нужно преобразовать.

Списки (list) — изменяемые упорядоченные коллекции: [1, 2, 3]. Кортежи (tuple) — неизменяемые: (1, 2, 3). Словари (dict) хранят пары ключ–значение: {'name': 'Айгерим', 'age': 19}. Множества (set) хранят уникальные элементы без порядка. Ключом словаря может быть только неизменяемый (хешируемый) объект, поэтому список нельзя использовать как ключ, а кортеж — можно.

Важно различать присваивание и копирование. После b = a обе переменные ссылаются на один и тот же список, и изменение b.append(4) изменит и a. Чтобы получить независимую копию, используют a.copy() или срез a[:].

Глава 2. Условия и циклы

Условный оператор if выполняет блок кода, если условие истинно. Дополнительные ветви задаются через elif, а ветвь по умолчанию — через else. Блоки кода в Python выделяются отступами, обычно четырьмя пробелами; неверный отступ приводит к ошибке IndentationError.

Ложными в условии считаются False, None, 0, 0.0, пустая строка, пустой список, пустой словарь и пустое множество. Все остальные значения считаются истинными. Поэтому проверку if len(items) > 0 можно записать короче: if items.

Операторы сравнения: ==, !=, <, >, <=, >=. Оператор == сравнивает значения, а оператор is проверяет, что две переменные ссылаются на один и тот же объект. Для проверки на None рекомендуется писать x is None. Логические операторы and, or, not вычисляются по короткой схеме: в выражении a and b значение b не вычисляется, если a ложно.

Цикл for перебирает элементы любой последовательности: списка, строки, словаря. Функция range(start, stop, step) создаёт последовательность чисел от start до stop, не включая stop. Например, range(1, 5) даёт 1, 2, 3, 4. Функция enumerate() возвращает пары индекс–элемент, а zip() перебирает несколько последовательностей параллельно.

Цикл while выполняется, пока условие истинно. Если условие никогда не станет ложным, получится бесконечный цикл. Оператор break немедленно завершает цикл, а continue переходит к следующей итерации. У циклов есть необязательная ветвь else, которая выполняется, если цикл завершился без break.

Изменять список во время его перебора циклом for опасно: при удалении элементов часть из них будет пропущена. Правильнее создать новый список, например с помощью генератора списка: evens = [x for x in numbers if x % 2 == 0].

Глава 3. Функции

Функция — это именованный блок кода, который можно вызывать многократно. Функция объявляется ключевым словом def, после которого идут имя, круглые скобки со списком параметров и двоеточие. Тело функции записывается с отступом.

Параметры — это имена, перечисленные в определении функции. Аргументы — это конкретные значения, которые передаются при вызове. В определении def area(width, height) width и height — параметры, а в вызове area(3, 4) числа 3 и 4 — аргументы.

Оператор return завершает функцию и возвращает значение. Если return отсутствует или записан без значения, функция возвращает None. Частая ошибка — использовать print внутри функции вместо return: print только выводит значение на экран, но не передаёт его вызывающему коду.

Аргументы можно передавать по позиции и по имени: area(height=4, width=3). Параметру можно задать значение по умолчанию: def greet(name, greeting='Сәлем'). Значения по умолчанию вычисляются один раз — в момент определения функции. Поэтому изменяемый объект, например список, в качестве значения по умолчанию опасен: он будет общим для всех вызовов. Правильный приём — использовать None и создавать список внутри функции.

Конструкции *args и **kwargs позволяют принимать произвольное число позиционных и именованных аргументов. Внутри функции args — это кортеж, а kwargs — словарь.

Переменные, созданные внутри функции, локальны: они не видны снаружи. Чтобы изменить глобальную переменную внутри функции, нужно объявить её через global, однако в хорошем коде так делают редко — лучше возвращать результат через return.

Лямбда-функция — это короткая анонимная функция из одного выражения: lambda x: x * 2. Лямбды часто передают как аргумент key в sorted(): sorted(students, key=lambda s: s['score']).

Рекурсивная функция вызывает саму себя. У рекурсии обязательно должен быть базовый случай, иначе возникнет ошибка RecursionError. Например, факториал: если n равно 0, вернуть 1, иначе вернуть n * factorial(n - 1). Повторные вычисления в рекурсии можно ускорить с помощью декоратора functools.lru_cache, который запоминает результаты уже выполненных вызовов.

Хорошая функция решает одну задачу, имеет понятное имя и небольшой размер. Разбиение программы на несколько маленьких функций упрощает тестирование и повторное использование кода.

Глава 4. Классы и объекты

Класс — это шаблон для создания объектов. Объект — экземпляр класса, у которого есть свои данные (атрибуты) и поведение (методы). Класс объявляется ключевым словом class.

Метод __init__ вызывается автоматически при создании объекта и используется для начальной установки атрибутов. Первым параметром любого обычного метода является self — ссылка на текущий объект. Через self.name = name создаётся атрибут объекта.

Наследование позволяет создать новый класс на основе существующего: class Student(Person). Дочерний класс получает атрибуты и методы родителя и может переопределять их. Функция super() позволяет вызвать метод родительского класса, например super().__init__(name).

Инкапсуляция в Python основана на соглашениях: атрибуты, имя которых начинается с подчёркивания, считаются внутренними и не предназначены для использования вне класса. Декоратор @property позволяет обращаться к методу как к атрибуту, например для вычисляемых значений.

Специальные методы позволяют настроить поведение объекта: __str__ задаёт строковое представление для print(), __len__ — результат функции len(), __eq__ — поведение оператора ==.

Атрибут класса общий для всех экземпляров, а атрибут экземпляра принадлежит конкретному объекту. Если в атрибуте класса хранится список, все объекты будут изменять один и тот же список — это частая ошибка начинающих.

Глава 5. Работа с файлами

Файл открывается функцией open(путь, режим). Основные режимы: 'r' — чтение (по умолчанию), 'w' — запись с полной перезаписью файла, 'a' — добавление в конец, 'b' — двоичный режим. Если открыть файл в режиме 'r', а файла не существует, возникнет ошибка FileNotFoundError.

Рекомендуется открывать файлы с помощью конструкции with open(...) as f. В этом случае файл закрывается автоматически, даже если внутри блока возникло исключение. Для текстовых файлов следует явно указывать кодировку: open('data.txt', encoding='utf-8'), иначе на разных операционных системах русский и казахский текст может прочитаться неправильно.

Метод read() читает весь файл в одну строку, readline() — одну строку, а перебор for line in f читает файл построчно и экономит память на больших файлах. Метод write() записывает строку и не добавляет перевод строки автоматически.

Ошибки при работе с файлами обрабатывают с помощью try и except. Блок finally выполняется в любом случае. Перехватывать стоит конкретные исключения, например FileNotFoundError, а не все подряд, чтобы не скрыть другие ошибки в программе.

Для табличных данных используют модуль csv, для структурированных — модуль json. Функция json.dump() записывает объект Python в файл в формате JSON, а json.load() читает его обратно. При записи русского текста стоит указывать ensure_ascii=False, чтобы символы сохранились в читаемом виде.
