# Запуск на Mac

Дважды нажмите `start.command`. При первом запуске потребуется интернет для установки зависимостей Python. Страница откроется в браузере автоматически. Оставьте окно терминала открытым, пока работаете; Ctrl+C останавливает сервер.

Готовая сборка интерфейса включена в проект. Открывать `index.html` двойным кликом не нужно: страница и API работают через общий сервер.

Для генерации вопросов впишите свой ключ в `backend/.env`: `OPENAI_API_KEY=...`. Этот файл создаётся при запуске и исключён из Git. После изменения ключа перезапустите приложение. Без ключа доступны интерфейс и загрузка материалов; генерация требует подключения к OpenAI.

Исходники подготовлены для репозитория https://github.com/mellisoul/mellisoul-100_Bal_AI . Локальная настройка не публикует сайт в интернете.

# 100 Bal AI

Генератор вопросов по учебным материалам (PDF/TXT) на основе OpenAI.

Загрузка документа → темы → вопросы 5 уровней сложности (тесты и открытые) → проверка качества → редактирование → тренировка.

## Запуск

```
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Открой `backend/.env` и впиши ключ: `OPENAI_API_KEY=sk-...` (модель задаётся в `OPENAI_MODEL`, по умолчанию `gpt-4o-mini`).

```
uvicorn main:app --reload
```

Открыть в Chrome: http://localhost:8000. Документация API: http://localhost:8000/docs

## Как это работает

- PyMuPDF достаёт текст постранично, TXT делится на условные страницы по ~3000 символов.
- Темы: AI читает материал окнами по ~12000 символов и возвращает темы с номерами страниц.
- Генерация: для выбранной темы берутся её страницы, для каждого уровня 1-5 идёт отдельный запрос с описанием уровня.
- Проверка качества: отдельный запрос к AI проверяет соответствие теме, правильность ответа и уровень; плюс отсев повторов по схожести текста.
- Каждый вопрос хранит тему, уровень, тип, страницу источника, ответ, объяснение и результат проверки.

## Тесты

```
cd backend
pip install pytest httpx
python -m pytest tests
```

Тесты используют подменённый AI, ключ не нужен.

## Разработка фронтенда

```
cd frontend
npm install
npm run dev
```

Откроется http://localhost:5173, запросы `/api` проксируются на backend (порт 8000). Перед коммитом: `npm run build`, чтобы обновить `frontend/dist`.
