# Бесплатная генерация Gemini

Создайте ключ на https://aistudio.google.com/apikey и вставьте в `backend/.env`: `GEMINI_API_KEY=...`. Используйте проект Free tier без платного биллинга. Квота ограничена; при её исчерпании будет ошибка без переключения на OpenAI. Если проект Google на платном тарифе, запросы оплачиваются по его тарифу. На бесплатном тарифе Google может использовать отправленные материалы для улучшения продуктов.

Модель: `gemini-3.5-flash-lite`. Все AI-запросы направляются в Google. Библиотека `openai` служит совместимым клиентом; ключ OpenAI игнорируется.

# Запуск на Mac

Дважды нажмите `start.command`. При первом запуске потребуется интернет для установки зависимостей Python. Страница откроется в браузере автоматически. Оставьте окно терминала открытым, пока работаете; Ctrl+C останавливает сервер.

Готовая сборка интерфейса включена в проект. Открывать `index.html` двойным кликом не нужно: страница и API работают через общий сервер.

Для генерации вопросов впишите свой ключ в `backend/.env`: `GEMINI_API_KEY=...`. Этот файл создаётся при запуске и исключён из Git. После изменения ключа перезапустите приложение. Без ключа доступны интерфейс и загрузка материалов; генерация требует подключения к Google Gemini.

Исходники подготовлены для репозитория https://github.com/mellisoul/mellisoul-100_Bal_AI . Локальная настройка не публикует сайт в интернете.

# 100 Bal AI

Генератор вопросов по учебным материалам (PDF/TXT) на основе Google Gemini.

Загрузка документа → темы → вопросы 5 уровней сложности (тесты и открытые) → проверка качества → редактирование → тренировка.

## Запуск

```
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Открой `backend/.env` и впиши ключ: `GEMINI_API_KEY=...` (модель задаётся в `GEMINI_MODEL`, по умолчанию `gemini-3.5-flash-lite`).

```
uvicorn main:app --reload
```

Открыть в Chrome: http://localhost:8000. Документация API: http://localhost:8000/docs

## Как это работает

- PyMuPDF достаёт текст постранично, TXT делится на условные страницы по ~3000 символов.
- Темы: AI читает материал окнами по ~12000 символов и возвращает темы с номерами страниц.
- Генерация: для выбранной темы берутся её страницы, для каждого уровня 1-5 идёт отдельный запрос с описанием уровня.
- Проверка качества: отдельный запрос к AI проверяет соответствие теме, правильность ответа и уровень; плюс отсев повторов по схожести текста.
- Каждый вопрос хранит тему, уровень, тип, страницу источника, ответ, объяснение и результат проверки.

## Тесты

```
cd backend
pip install pytest httpx
python -m pytest tests
```

Тесты используют подменённый AI, ключ не нужен.

## Разработка фронтенда

```
cd frontend
npm install
npm run dev
```

Откроется http://localhost:5173, запросы `/api` проксируются на backend (порт 8000). Перед коммитом: `npm run build`, чтобы обновить `frontend/dist`.

## Публичная ссылка (Render)

Проект разворачивается на Render одной кнопкой по файлу `render.yaml`:

1. https://render.com/deploy?repo=https://github.com/mellisoul/mellisoul-100_Bal_AI
2. Войти через GitHub, указать `GEMINI_API_KEY`, нажать **Deploy**.
3. Получится ссылка вида `https://100-bal-ai.onrender.com` — её можно открыть с любого компьютера, ключ хранится на сервере.

Ограничения бесплатного тарифа: после 15 минут без посетителей сервер засыпает, первое открытие занимает до минуты; база SQLite сбрасывается при перезапуске сервера. Запросы к AI ограничены `AI_LIMIT_PER_HOUR` на один IP.
